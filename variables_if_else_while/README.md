# Variables, if, else, while

Projet C du cursus Holberton School.

## Description

Ce dossier contient des programmes en C qui utilisent :
- les variables (`char`, `int`, `unsigned int`)
- les opérateurs arithmétiques, relationnels et logiques
- les structures `if` et `if ... else`
- les boucles `while`

## Compilation

Les fichiers sont compilés sur Ubuntu 20.04 LTS avec :

    gcc -Wall -Werror -Wextra -pedantic -std=gnu89
