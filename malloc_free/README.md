# C - malloc, free
Projet sur l'allocation dynamique de mémoire en C (malloc et free).

## Tâches
- 0. create_array : crée un tableau de chars initialisé avec un caractère donné.
- 1. _strdup : retourne un pointeur vers une copie d'une chaîne, allouée avec malloc.
- 2. str_concat : concatène deux chaînes dans un nouvel espace mémoire alloué avec malloc.
